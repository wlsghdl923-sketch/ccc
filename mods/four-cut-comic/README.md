# four-cut-comic

역할을 하나씩 맡은 Claude 서브에이전트 6명이 협업해 『월간순정 노자키군』 팬 4컷 만화를 만드는 Claude Code 모드(플러그인)입니다.

## 사용법

```
/4cut 치요의 밸런타인 초콜릿
```

결과물:
- `comics/<슬러그>/comic.md` — 스토리, 콘티, 대사, 편집 판정, 이미지 생성 AI용 프롬프트
- `comics/<슬러그>/preview.html` — 말풍선 배치를 확인하는 4컷 레이아웃 미리보기(단순 도형)

## 역할

| 에이전트 | 역할 | 도구 |
| --- | --- | --- |
| `story-writer` | 1. 노자키군 캐릭터·개그 구조로 기승전결 플롯 | Read |
| `storyboarder` | 2. 컷별 구도, 인물 배치(좌/중/우), 표정·동작, 배경 | Read |
| `dialogue-writer` | 3. 대사(컷당 2개, 20자 이내)와 말풍선 위치·종류·순서 배치 | Read |
| `comic-editor` | 4. 통과/수정 판정, 담당별 수정 지시 (최대 2회 반복) | Read |
| `image-prompter` | 5. 인물별 캐릭터 시트 프롬프트 + 컷별 이미지 프롬프트 | Read |
| `layout-artist` | 6. 인라인 SVG 4컷 미리보기 HTML | Read, Write |

진행 순서: 스토리 → 콘티 → 대사 → 편집(수정 루프) → 이미지 프롬프트·레이아웃(병렬) → 저장.
메인 Claude는 순서 진행과 파일 저장만 하고, 각 에이전트는 자기 역할 밖의 내용은 바꾸지 않습니다.
에이전트는 `four-cut-comic:story-writer`처럼 직접 호출할 수도 있습니다.

## 아이디어 찾기 (`/4cut-idea` → 고르기 → `/4cut-check`)

역할 분담: Claude가 많이 뽑고, 사람이 고르고, 고른 것만 자료로 점검합니다. "웃긴가"는 사람이 판단하고, AI는 사람이 하기 어려운 902편 대조(원작 겹침·캐릭터 모순)만 맡습니다.

1. `references/nozaki/` 에 패턴 도감 자료가 있어야 합니다(README 참고).
2. `/4cut-idea` 또는 `/4cut-idea 시험 기간, 20개` — 한 줄 아이디어 목록을 `ideas/<슬러그>/pitches.md` 에 저장하고 보여 줍니다.
3. 마음에 드는 번호를 고릅니다.
4. `/4cut-check <슬러그> 3 7 12` — 고른 것만 원작 겹침(연작 단위)과 캐릭터 근거·반례를 확인해 통과/주의/걸림과 피하는 법을 알려 줍니다. 점수는 매기지 않습니다.

| 에이전트 | 역할 | 도구 |
| --- | --- | --- |
| `pitch-writer` | 도감의 흐름 54개와 인물 조합을 섞어 한 줄 아이디어를 많이 발상 | Read, Glob, Grep |
| `idea-gate` | 고른 아이디어의 원작 겹침·캐릭터 모순 확인 | Read, Glob, Grep |
| `idea-scout`, `idea-checker` | (심화용) 근거를 붙인 상세 아이디어 작성과 30점 채점. 기준 25/30·모든 기준 4점 이상은 원작 대표 편 상위 약 25% 수준(원작 8편 평균 24.75) | Read, Glob, Grep |

## 내 캐릭터 세트 (`/4cut-cast`)

원작에서는 웃음 구조(유형·흐름)만 빌리고, 등장인물은 내가 만든 캐릭터로 4컷을 기획할 수 있습니다. 세트 하나 = 작품 하나이며 `casts/<세트ID>/cast.md` 에 저장됩니다(템플릿 `casts/_template.md`).

1. `/4cut-cast` — 세트 목록과 새 세트에 필요한 질문을 봅니다.
2. `/4cut-cast my-school <설정·인물 설명>` — `cast-keeper` 가 템플릿에 정리해 저장하고, 비어 있는 핵심 항목(기준·겉↔실제·역할 경향·관계)과 모순을 짚어 다음 질문을 줍니다. 말하지 않은 설정은 지어내지 않고 (미정)으로 둡니다.
3. `/4cut-idea my-school [주제, 개수]` — 그 세트 인물만으로 한 줄 아이디어를 뽑습니다.
4. `/4cut-check <슬러그> 번호들` — 원작과의 구조 겹침, 세트 설정과의 모순(하지 않는 행동 등)을 점검합니다.

| 에이전트 | 역할 | 도구 |
| --- | --- | --- |
| `cast-keeper` | 세트 만들기·고치기(버전·변경 기록), 빈 항목·모순 점검, 아이디어용 요약(brief.md) | Read, Glob, Grep, Write |

## 한계

원작 캐릭터를 쓰는 팬 창작물이므로 개인 감상·비영리 공유 범위를 넘는 이용(판매 등)은 저작권 문제가 될 수 있습니다. 캐릭터 외형 키워드 일부(머리색 등)는 원작과 대조해 확인이 필요합니다.


Claude는 완성된 그림을 그리지 않습니다. 실제 그림은 `image-prompter`가 만든 프롬프트를 이미지 생성 AI에 넣어 얻고, 대사는 편집 툴로 얹어야 합니다.

## 설치

이 폴더를 `--plugin-dir`로 지정하거나 `CLAUDE_CODE_PLUGIN_DIRS`에 추가합니다.

```
claude --plugin-dir ./mods/four-cut-comic
```
