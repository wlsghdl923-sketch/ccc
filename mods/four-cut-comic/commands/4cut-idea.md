『월간순정 노자키군』 자료를 근거로 4컷 만화 아이디어를 찾는다. 콘티는 만들지 않는다.
요청 조건: $ARGUMENTS (비어 있으면 주제 자유, 아이디어 5개)

자료 폴더는 현재 작업 디렉터리의 `references/nozaki/` 이다. 먼저 Glob으로 README.md 를 뺀 파일이 있는지 확인하라. 없으면 서브에이전트를 부르지 말고, 사용자에게 그 폴더에 자료(텍스트·PDF·이미지)를 넣어 달라고만 말하고 끝낸다.

자료가 있으면 아래 순서대로 Agent 도구로 서브에이전트를 호출한다. 너(메인)는 진행과 저장만 하고 내용은 직접 쓰지 않는다. 단계 사이 전달은 파일 경로로 한다.

1. four-cut-comic:idea-scout — 자료 폴더의 절대 경로와 요청 조건을 넘긴다. 결과 전문을 `ideas/<영문-슬러그>/1-ideas.md` 에 저장한다(슬러그는 주제가 없으면 날짜).
2. four-cut-comic:idea-checker — 자료 폴더 경로와 1-ideas.md 경로를 넘긴다. 결과를 `ideas/<슬러그>/2-review.md` 에 저장한다.
3. 판정이 "보완"인 아이디어가 있으면 한 번만 보완한다: idea-scout에게 1-ideas.md, 2-review.md 경로와 "보완 판정 아이디어만 보완 지시대로 고쳐 같은 형식(B 섹션)으로 다시 써라"를 넘겨 `ideas/<슬러그>/3-revised.md` 에 저장하고, idea-checker에게 그 파일을 재검토시켜 `ideas/<슬러그>/4-review.md` 에 저장한다. 보완은 최대 1회.
4. 사용자에게 짧게 보고한다: 채택된 아이디어(가제, 점수, 한 줄 전제, 사용 패턴), 보완·폐기 개수, 근거 검증에서 "확인 불가"가 나온 패턴, 저장된 파일 경로.
