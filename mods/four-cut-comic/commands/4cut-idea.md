『월간순정 노자키군』 패턴 도감을 근거로 한 줄 4컷 아이디어를 뽑는다. 역할 분담: Claude는 많이 뽑고, 사용자가 고르고, 고른 것만 /4cut-check 로 점검한다.
요청 조건: $ARGUMENTS (비어 있으면 주제 자유, 30개)
첫 단어가 casts/<그 단어>/cast.md 로 존재하면 그것이 캐릭터 세트ID다. 세트ID가 있으면 casts/<세트ID>/brief.md 가 없을 때 four-cut-comic:cast-keeper 로 먼저 캐스트 요약을 만든다.

자료 폴더는 현재 작업 디렉터리의 `references/nozaki/` 이다. 먼저 Glob으로 01_types.md, 02_flows.md 가 있는지 확인하라. 없으면 사용자에게 자료를 넣어 달라고만 말하고 끝낸다.

1. Agent 도구로 four-cut-comic:pitch-writer 를 호출한다. 자료 폴더의 절대 경로, 세트ID(있으면, casts 폴더 절대 경로와 함께), 요청 조건(주제, 개수)을 넘긴다. 너(메인)는 내용을 직접 쓰지 않는다.
2. 결과 전문을 `ideas/<슬러그>/pitches.md` 에 저장한다(슬러그는 [세트ID-]주제 영문, 주제가 없으면 [세트ID-]날짜-시각 예: my-school-2026-10-25-1530). 파일 첫 줄에 "세트: <세트ID 또는 원작>"을 적는다.
3. 사용자에게 목록을 그대로 보여 주고(요약하지 말 것), 마음에 드는 번호를 골라 `/4cut-check <슬러그> <번호들>` 로 점검하라고 안내한다. 여기서 멈춘다. 점검이나 다듬기를 먼저 하지 않는다.
