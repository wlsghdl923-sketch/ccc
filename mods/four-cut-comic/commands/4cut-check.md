---
description: 고른 한 줄 아이디어만 원작 겹침·캐릭터 모순 점검 (예: /4cut-check 2026-10-25-1530 3 7 12)
argument-hint: "<슬러그> <번호들>"
---
사용자가 /4cut-idea 목록에서 고른 아이디어만 점검한다. 점수는 매기지 않는다.
입력: $ARGUMENTS  (첫 단어 = 슬러그, 나머지 = 번호들)

1. `ideas/<슬러그>/pitches.md` 를 Read 해서 고른 번호의 아이디어만 뽑는다. 파일이나 번호가 없으면 사용자에게 알리고 끝낸다.
2. pitches.md 첫 줄의 "세트:"를 확인한다. Agent 도구로 four-cut-comic:idea-gate 를 호출한다. 자료 폴더(현재 작업 디렉터리의 references/nozaki/ 절대 경로), 세트ID와 casts/<세트ID>/cast.md 절대 경로(세트가 있으면), 고른 아이디어 원문을 그대로 넘긴다. 번호가 6개 이상이면 3개씩 나눠 여러 idea-gate를 한 메시지에서 병렬로 호출한다.
3. 결과를 `ideas/<슬러그>/check-<번호들>.md` 에 저장한다.
4. 사용자에게 요약 표(번호, 가제, 통과/주의/걸림, 핵심 이유)와 주의·걸림의 피하는 법을 보여 준다. 살릴 아이디어를 다듬거나 콘티로 넘길지는 사용자가 정한다.
