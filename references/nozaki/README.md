# 노자키군 자료 폴더

`/4cut-idea` 가 읽는 자료를 여기에 넣습니다. 이 README는 읽지 않습니다.

- 형식: `.md`, `.txt`, `.pdf`, 이미지(`.png`, `.jpg`)
- 예: 에피소드 줄거리 정리, 캐릭터 설정 메모, 좋아하는 장면 요약, 만화 페이지 캡처
- 파일명에 화수나 주제를 넣으면 근거 표시가 정확해집니다 (예: `ep05_치요_고백.md`).
- 원작 페이지 이미지나 스캔본을 공개 저장소에 커밋하면 저작권 문제가 될 수 있습니다. 공개 저장소라면 줄거리를 직접 요약한 텍스트를 권장합니다.

## 현재 들어 있는 자료

사용자 아티팩트 「노자키군 4컷 패턴 도감」(1~7권 902편 분석)에서 뽑은 텍스트입니다.

| 파일 | 내용 | 커밋 |
| --- | --- | --- |
| `00_overview.md` | 통계, 권별 변화, 칸별 규칙, 연재 설계, 가설 수정 | O |
| `01_types.md` | 웃음 유형 8가지(+기타)의 흐름·변형·대표 편 | O |
| `02_flows.md` | 유형별 4컷 흐름 54개와 근거 편 | O |
| `03_issues.md` | 70호의 중심 인물·주제·유형 | O |
| `strips/vol1~7.md` | 902편 목록(컷별 대사 전사, 웃음 원리, 여지, 3컷 역할 등) | X (원작 대사 포함, `.gitignore`) |

`strips/` 는 컨테이너가 바뀌면 사라집니다. 아티팩트를 HTML로 받아 다시 만들면 됩니다:

```
python -I references/tools/extract_pattern_atlas.py <도감.html> references/nozaki
```
