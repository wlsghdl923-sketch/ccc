# 노자키군 자료 폴더

`/4cut-idea` 가 읽는 자료를 여기에 넣습니다. 이 README는 읽지 않습니다.

- 형식: `.md`, `.txt`, `.pdf`, 이미지(`.png`, `.jpg`)
- 예: 에피소드 줄거리 정리, 캐릭터 설정 메모, 좋아하는 장면 요약, 만화 페이지 캡처
- 파일명에 화수나 주제를 넣으면 근거 표시가 정확해집니다 (예: `ep05_치요_고백.md`).
- 원작 페이지 이미지나 스캔본을 공개 저장소에 커밋하면 저작권 문제가 될 수 있습니다. 공개 저장소라면 줄거리를 직접 요약한 텍스트를 권장합니다.
