# wmremover

이미지의 워터마크를 자동으로 찾아서 자연스럽게 지우는 도구입니다.

> **개발을 모르시는 Windows 사용자**는 [`사용방법.txt`](사용방법.txt)를 보세요.
> 요약: 폴더를 받아 압축을 풀고 → `start.bat` 더블클릭 → 브라우저 화면에 사진이나 zip을 끌어다 놓기.

- **검출**: 워터마크 위치를 자동으로 찾습니다 (아래 두 방식).
- **복원**: [LaMa](https://github.com/advimman/lama) 딥러닝 인페인팅으로 지운 자리를 채웁니다. PyTorch가 없으면 OpenCV 인페인팅으로 대체합니다.

## 설치

```bash
pip install -e ".[full]"      # LaMa + 텍스트 검출 (권장)
pip install -e .              # 최소 설치: 일괄 검출 + OpenCV 인페인팅만
```

LaMa 모델(약 200MB)은 처음 실행할 때 `~/.cache/wmremover`에 받아지고, CRAFT 텍스트 검출 모델은 `~/.EasyOCR`에 받아집니다.

## 사용법

```bash
wmremover photo.jpg -o out/                # 한 장
wmremover photos/ -o out/ --save-mask      # 폴더 전체, 검출 마스크도 저장
wmremover 사진모음.zip -o 결과.zip          # zip을 넣고 zip으로 받기 (폴더 구조 유지)
wmremover photo.jpg --mask mask.png        # 자동 검출 대신 직접 만든 마스크 사용 (흰색 = 지울 영역)
wmremover-app                              # 브라우저 화면 실행 (pip install -e ".[full,app]")
```

입력은 이미지 파일, 폴더, zip을 섞어서 넣을 수 있습니다. Windows 압축 프로그램(알집, 탐색기)이 만든 zip의 한글 파일명(CP949)도 올바르게 읽습니다. 알집 전용 형식(`.alz`, `.egg`)은 지원하지 않습니다.

| 옵션 | 설명 |
|---|---|
| `-m consensus,text` | 사용할 검출기 (기본값: 둘 다) |
| `-s 0.5` | 민감도 0~1. 높이면 옅은 워터마크도 찾지만 오탐이 늘고 느려짐 |
| `-i auto\|lama\|opencv` | 인페인팅 방식 |
| `--save-mask` | `<이름>_mask.png` 저장 (결과 확인용) |

Python API:

```python
import cv2
from wmremover import remove_watermarks

imgs = [cv2.imread(p) for p in paths]
for result, mask in remove_watermarks(imgs):
    ...
```

## 검출 방식과 한계

### 1. 일괄 검출 (`consensus`) — 같은 워터마크가 찍힌 이미지 여러 장

같은 크기의 이미지가 3장 이상 있으면 자동으로 사용합니다. 여러 장에서 같은 위치·같은 방향으로 나타나는 그래디언트만 남기고, 이를 Poisson 적분해 워터마크 형태를 복원합니다 (Dekel et al., *On the Effectiveness of Visible Watermarks*, CVPR 2017 방식). **텍스트와 로고를 모두** 정확하게 잡으며, 워터마크가 없는 이미지 묶음에서는 아무것도 검출하지 않습니다.

합성 워터마크 평가 (실제 사진 위, 640×480):

| 워터마크 | 3장 | 5장 | 14장 |
|---|---|---|---|
| 흰색 텍스트 35% | 재현율 0.96 / 정밀도 0.68 | 1.00 / 0.76 | 1.00 / 1.00 |
| 흰색 로고 40% | 1.00 / 0.52 | 1.00 / 0.88 | 1.00 / 1.00 |
| 검은색 대각선 텍스트 30% | 1.00 / 0.70 | 1.00 / 0.95 | 1.00 / 1.00 |
| 모서리 작은 텍스트 70% | 0.16 / 0.04 | 1.00 / 0.89 | 1.00 / 1.00 |
| 흰색 텍스트 15% (매우 옅음) | 0.80 / 0.38 | 0.44 / 0.30 | 0.78 / 0.74 |

장수가 적으면 한 장이라도 워터마크가 배경에 묻혀 안 보일 때 놓칠 수 있습니다 (예: 3장 중 1장이 흰 하늘 위의 흰 워터마크). 5장 이상을 권장합니다.

### 2. 텍스트 검출 (`text`) — 이미지 한 장

CRAFT 텍스트 검출기를 원본과 대비 강화본(CLAHE)에 돌려 글자 영역을 찾습니다.

- 모서리의 불투명 텍스트 워터마크: 재현율 약 0.9
- 크고 반투명한 텍스트 (35~40%): 재현율 약 0.7
- **알려진 한계**
  - 워터마크 글자와 사진 속 글자를 구분하지 못합니다. 간판, 유니폼 로고, 기판 인쇄처럼 원래 사진에 있는 글자도 지웁니다.
  - 글자가 아닌 로고(도형 마크)는 찾지 못합니다.

한 장짜리 이미지에서 이 두 한계를 해결하려면 워터마크 전용으로 학습된 검출 모델이 필요합니다.
